# 🤖 Amir_Dig

### دستیار هوش مصنوعی فارسی‌زبان — رفیق، رک، دقیق

یه برنامه‌ی چت دسکتاپ که فقط و فقط فارسی حرف می‌زنه، خودمونی جواب می‌ده، سرچ وب می‌کنه، عکس می‌بینه و با امنیت کامل روی ویندوز اجرا می‌شه.

## 🎯 Amir_Dig چیه؟

**Amir_Dig** یه دستیار هوش مصنوعی فارسی‌زبانه که روی ویندوز نصب می‌شه و باهاش می‌تونی مثل یه رفیق حرف بزنی.

برخلاف دستیارهای دیگه که وسط فارسی، چینی یا عربی قاطی می‌کنن، Amir_Dig:

- 🗣️ **فقط فارسی حرف می‌زنه** — تمیز و روان
- 🤝 **خودمونی و رفیقانه جواب می‌ده** — نه خشک و اداری
- 🔍 **سرچ وب می‌کنه** — قیمت دلار، اخبار، آخرین نسخه‌ها
- 📸 **عکس می‌بینه** — اسکرین‌شات بفرست، تحلیل می‌کنه
- 🔒 **توکن شما رو رمزنگاری می‌کنه** — امن و مطمئن
- ⚡ **روی دسکتاپ ویندوز** با یه کلیک باز می‌شه

## 🔑 گرفتن کلید OpenRouter

برای اینکه Amir_Dig بتونه جواب بده، به **کلید رایگان OpenRouter** نیاز داری. این کار ۲ دقیقه طول می‌کشه:

### مراحل

1. اگه حساب نداری، برو به [openrouter.ai](https://openrouter.ai) و ثبت‌نام کن (فقط ایمیل، **بدون کارت بانکی**)

2. برو به این لینک:

   👉 [**openrouter.ai/keys**](https://openrouter.ai/keys)

3. روی **Create Key** کلیک کن

4. یه اسم دلخواه بذار (مثلاً `Amir_Dig`)

5. کلید رو کپی کن (شروع می‌شه با `sk-or-v1-...`)

6. توی Amir_Dig پیستش کن و **ادامه** رو بزن

> 🔒 **امنیت:** Amir_Dig کلید رو رمزنگاری‌شده روی سیستم خودت ذخیره می‌کنه. به هیچ سروری نمی‌فرسته (به‌جز OpenRouter که خودت داری باهاش حرف می‌زنی).

### 🔢 سقف رایگان OpenRouter

| وضعیت | درخواست در روز |
|-------|----------------|
| **بدون اعتبار** | ۵۰ |
| **با ۱۰ دلار اعتبار** | ۱۰۰۰ (دائمی) |

> 💡 اگه مصرف روزانه‌ت بالاست، یه بار ۱۰ دلار به OpenRouter بده. سقفت از ۵۰ به ۱۰۰۰ می‌رسه و **دائمی** باقی می‌مونه.

## 🔍 کلید Tavily (اختیاری)

Amir_Dig برای سرچ وب، به کلید Tavily نیاز **نداره** — ولی اگه داشته باشی، سرعت و کیفیت سرچ بالاتر می‌ره.

### مراحل

1. برو به [tavily.com](https://tavily.com) و ثبت‌نام کن (رایگان)

2. کلید API رو کپی کن (شروع می‌شه با `tvly-...`)

3. توی Amir_Dig پیستش کن

> 💡 اگه Tavily نداری، برنامه خودش از **DuckDuckGo**، **Litescrape**، **Parallel** و **Wikipedia** استفاده می‌کنه.

## ❓ سوالات متداول

<details>
<summary><b>🔴 برنامه باز نمی‌شه</b></summary>

**راه‌حل:**
1. ویندوزت باید ۱۰ یا ۱۱ (۶۴ بیت) باشه
2. اگه آنتی‌ویروس بلاکش کرده، بهش اجازه بده
3. یه بار ری‌استارت کن و دوباره امتحان کن

</details>

<details>
<summary><b>🔴 خطای «کلید OpenRouter معتبر نیست»</b></summary>

**راه‌حل:**
1. مطمئن شو کلید رو کامل کپی کردی (شروع می‌شه با `sk-or-v1-`)
2. کلیدت رو از [openrouter.ai/keys](https://openrouter.ai/keys) دوباره چک کن
3. اگه منقضی شده، یه کلید جدید بساز

</details>

<details>
<summary><b>🔴 خطای «شبکه برقرار نشد»</b></summary>

**راه‌حل:**
1. VPN / پروکسی رو روشن کن
2. Amir_Dig رو ببند و دوباره باز کن
3. اگه بازم نشد، پروکسی رو با یه برنامه‌ی دیگه امتحان کن

</details>

<details>
<summary><b>🔴 پیام «سقف روزانه پر شده» می‌ده</b></summary>

**راه‌حل:**
- OpenRouter روزی **۵۰ درخواست رایگان** بهت می‌ده
- برای ۱۰۰۰ درخواست در روز، **۱۰ دلار** به حساب OpenRouter اضافه کن (دائمی)
- یا ۲۴ ساعت صبر کن تا سقف ریست بشه

</details>

<details>
<summary><b>🔴 برنامه انگلیسی یا چینی جواب می‌ده</b></summary>

**راه‌حل:**
1. تنظیمات → AI / Model → مدل رو عوض کن به **Nemotron 3 Ultra** یا **Ling 3.0 Flash VL**
2. Temperature رو کمتر کن (مثلاً `0.2`)
3. از System Prompt این متن رو اضافه کن: «فقط و فقط فارسی جواب بده»

</details>

<details>
<summary><b>🔴 سرچ کار نمی‌کنه</b></summary>

**راه‌حل:**
1. VPN رو روشن کن
2. اگه کلید Tavily داری، از تنظیمات پاکش کن (شاید منقضی شده)
3. برنامه رو ری‌استارت کن

</details>

<details>
<summary><b>🔴 می‌خوام عکس بفرستم</b></summary>

**راه‌حل:**
1. روی دکمه‌ی 📎 کنار کادر تایپ بزن
2. عکس رو انتخاب کن (JPEG، PNG، WebP یا GIF، حداکثر ۱۵ مگابایت)
3. سؤالت رو بنویس و بفرست

</details>

<details>
<summary><b>🔴 چطور چت‌هام رو بایگانی کنم؟</b></summary>

**راه‌حل:**
1. روی آیکون ⋮ کنار اسم چت کلیک کن (یا راست‌کلیک)
2. **بایگانی** رو بزن
3. چت می‌ره تب «بایگانی» — هر وقت خواستی از اونجا برش گردون

</details>

<details>
<summary><b>🔴 چطور کلیدم رو پاک کنم؟</b></summary>

**راه‌حل:**
1. تنظیمات → Token / Account
2. دکمه‌ی **حذف** رو بزن
3. کلید جدید وارد کن

</details>

<details>
<summary><b>🔴 می‌تونم ازش توی موبایل استفاده کنم؟</b></summary>

فعلاً نه. Amir_Dig فقط برای **ویندوز** ساخته شده. نسخه‌ی موبایل توی برنامه‌های آینده هست.

</details>

## 🎁 مدل‌های پشتیبانی‌شده

Amir_Dig از این مدل‌های **رایگان OpenRouter** پشتیبانی می‌کنه (توی تنظیمات قابل انتخاب):

| مدل | حجم | کیفیت فارسی | سرعت |
|-----|-----|-------------|------|
| **Auto (Free Router)** 🏆 | متغیر | عالی | خودکار |
| **Nemotron 3 Ultra** | 550B | 🏆 عالی | متوسط |
| **Nemotron 3 Super** | 120B | 🏆 عالی | سریع |
| **Nemotron 3.5 Lightning** | - | ⭐ خوب | 🚀 خیلی سریع |
| **Ling 3.0 Flash VL** | - | ⭐ خوب | سریع (+ Vision) |
| **Laguna S 2.1** | - | ⭐ خوب | سریع (کد) |
| **Dots3 Note** | - | ⭐ خوب | متوسط (+ Vision) |
| **Cohere North Mini** | - | ⭐ خوب | سریع (کد) |

> 💡 **پیشنهاد:** گزینه‌ی **Auto (Free Router)** رو انتخاب کن — خودش بهترین مدل رایگان موجود رو انتخاب می‌کنه.
