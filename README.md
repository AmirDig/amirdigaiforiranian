# Amir_Dig AI

### Desktop AI Assistant for Persian Users

Amir_Dig AI یک دستیار هوش مصنوعی دسکتاپ با تمرکز ویژه بر تجربه فارسی است.

## Download

### Windows

آخرین نسخه Setup را از بخش **Releases** دریافت کنید:

**`Amir_Dig_Setup.exe`**

پس از دانلود، فایل Setup را اجرا کنید و مراحل نصب را انجام دهید.

## Features

- رابط کاربری فارسی و مدرن
- چت با هوش مصنوعی
- اتصال به Hugging Face
- انتخاب مدل
- Streaming
- مدیریت چند Chat
- Pin / Delete / Rename Chat
- Search
- Settings
- Dark / Light / System
- Avatar برای User و AI
- فونت فارسی
- پشتیبانی از متن فارسی و انگلیسی

## AI Provider

**Hugging Face**

مدل پیش‌فرض:

```text
Qwen/Qwen3-235B-A22B-Instruct-2507
````

## Requirements

* Windows
* اتصال اینترنت برای استفاده از سرویس AI
* Hugging Face Token

## Repository

`amirdigaiforiranian`

## Installation

1. فایل `Amir_Dig_Setup.exe` را دانلود کنید.
2. Setup را اجرا کنید.
3. برنامه را نصب کنید.
4. برنامه را اجرا کنید.
5. Hugging Face Token خود را وارد کنید.

برای دریافت جدیدترین نسخه، بخش **Releases** را بررسی کنید.
